# JobMatchly videos

Two 1920×1080, 30fps H.264 product films, rendered from code.

| Film | Source | Output | Length |
| --- | --- | --- | --- |
| Launch: CV tailoring | `index.html` | `out/jobmatchly-launch.mp4` | 24.5s |
| Features: jobs, daily alerts, articles, all free | `features.html` | `out/jobmatchly-features.mp4` | 45s |

The features film is slower-paced and framed closer, so the UI reads on a phone.
Its claims map to code: listing reasons from `lib/jobs/match.ts`, the daily
digest (`lib/jobs/digest.ts`, run after the 05:00 `jobs-ingest` cron) and its
email layout (`lib/mail.ts`), article categories from `data/enrich.ts`, and
"All free" from the free column in `app/pricing/page.tsx`.

## How it works

- `index.html` is the whole composition. Every frame is a pure function of time
  (`window.renderAt(t)`), so renders are deterministic and repeatable.
- `render.mjs` serves the repo root, opens the page in Playwright's Chromium,
  steps through time at 30fps, and pipes PNG frames straight into FFmpeg
  (libx264, CRF 16, yuv420p, faststart).
- `icons.js` holds the exact Lucide glyphs the wizard uses. It is generated by
  `extract-icons.mjs` from the installed `lucide-react`.
- `contact-sheet.py` tiles QC stills into one image for review.

It is self-contained. Nothing in the app imports it, Tailwind and ESLint don't
scan `marketing/`, and `tsconfig` only picks up `.ts`/`.tsx` files.

## Source of truth

The product screens rebuild the real tailoring wizard in `app/app/upload-tailor`:

| Beat | Real source |
| --- | --- |
| Upload, "Parsing your resume…", "Parsed successfully" | `components/StepOne.tsx` |
| Paste Text / Image (OCR) tabs, tip, character count, "Tailor my resume" | `components/StepTwo.tsx` |
| Parsing → Normalizing → Analyzing → Tailoring → Exporting pills, "Cancel & Reset" | `components/WizardStepper.tsx` |
| Overlay labels "Cleaning JD…", "Analyzing your resume & JD…", "Tailoring your resume…" | `StepTwo.tsx` (`jdLabel`) |
| Tailored Resume / Cover Letter tabs, toolbar, Download PDF, Generate Cover Letter, Changes Summary | `components/StepThree.tsx` |
| Resume styling (navy name, blue section rules) | `templates/Classic.tsx` |
| Toast copy | the `toast.success(...)` calls in the steps above |
| Colours, fonts, radius | `app/globals.css` (`.dark`), `@fontsource-variable/*` |
| Logo | `public/jobmatchly-logo.svg` |

The candidate (Thandi Nkosi), the job ad (Umoya Financial Services), and the
resume and cover-letter text are illustrative sample content. The video shows
no scores, statistics or testimonials.

## Rendering

```bash
# one-time: an FFmpeg with libx264 (skip if ffmpeg is on PATH or FFMPEG_PATH is set)
pip install imageio-ffmpeg

# full renders (--workers renders frame ranges in parallel, then joins them losslessly)
node marketing/launch-video/render.mjs --workers 6                        # -> out/jobmatchly-launch.mp4
node marketing/launch-video/render.mjs --page features.html --workers 6   # -> out/jobmatchly-features.mp4

# QC stills at chosen timestamps -> out/stills/
node marketing/launch-video/render.mjs --stills 1.6,5.4,10.9,14.6,22
python marketing/launch-video/contact-sheet.py marketing/launch-video/out/sheet.png 1.6 5.4 10.9 14.6 22

# render only a section
node marketing/launch-video/render.mjs --from 9 --to 13 --out out/clip.mp4
```

To preview in a browser, serve the repo root (e.g. `npx serve .`) and open
`/marketing/launch-video/index.html?play` to loop it, or `?t=14.6` to freeze on
one moment.
